# 自助打包台取货屏 Demo

基于穹彻机器人取货屏 Figma 稿更新。原生 HTML / CSS / JavaScript，不需要构建。

## 使用

在仓库目录运行 `python3 -m http.server 4173`，打开 `http://localhost:4173/`。

右下角「演示控制」支持：

- 切换 1～8 个有订单的框；也可直接按数字键 1～8。
- 预览异常订单、8 号框暂停使用。
- 切换 Figma 稿示例与叁悦广场店历史订单。
- 全屏预览；Esc 退出。

## 页面范围

- 蓝色取货屏、白色微青异形框、深蓝出纸口、小票、药品模型。
- 正常比例的平台标签、正圆框号、可直接修改的 HTML 文字；不对文字做缩放、斜切或透视变形。
- 1 / 2 / 3 单排；4 为 2+2；5～8 为 4+1 / 4+2 / 4+3 / 4+4。
- 可取货、分拣中、灰色异常框（交叉锁链＋挂锁）、暂停使用。
- 待分拣列表仅展示平台与流水号。

## 数据与边界

默认 Figma 示例保留稿中的美团 #74、淘宝 #28 等标签，属于设计示例。
「叁悦历史订单」使用 2026-11-09 已核对的订单内容，流水号保留原样；公开版仅包含平台、流水号、药品名称与数量，无完整订单号或个人信息。
框位、分拣状态与等待列表均为演示编排。没有连接生产订单或机器人，不执行真实取货、库存或设备操作。
药品是简化模型，盒型与摆放仅作视觉示意；悬停模型可查看药品名称和数量。

## 交付与核对

参考画板为 2560×1600；另检查了 1920×1080 和 1440×900 的横屏布局。未声明手机竖屏设计保真。
模型、纸张和锁链为独立图片 / SVG 资产；所有动态信息由语义化 DOM 与统一前端状态渲染。
